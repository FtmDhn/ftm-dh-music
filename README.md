# Ftm-Dh Music 

> **Music isn't just something you play.  
> It's something you experience.**

Ftm-Dh Music is a modern, responsive music player built with **Vanilla JavaScript and Tailwind CSS**.

The goal was to create more than just a music player — a simple and immersive space where users can discover music, search for songs, play their favorites, and build their own library.

## 🎵 The Concept

The project focuses on creating a clean and modern music experience through:

- Dynamic music playback
- Song search
- Like & Library system
- Music categories
- Artist sections
- Responsive sliders
- Keyboard interactions
- Responsive dark UI

> **Find your music. Like what you love. Press play.**

##  What I Practiced

This project helped me take my JavaScript skills beyond simple interactions and build a more dynamic application.

- **DOM Manipulation:** Creating and updating music elements dynamically.
- **Event Handling:** Managing player controls and user interactions.
- **Search Logic:** Finding and displaying songs based on user input.
- **Library Management:** Saving and displaying liked songs.
- **State Management:** Managing the active song and liked tracks.
- **Responsive UI:** Building a consistent experience across different screens.
- **Swiper.js:** Creating interactive music and artist sliders.
- **Tailwind CSS:** Building the UI with utility-first CSS.

##  Features

## Getting Started

No build tools or dependencies required.

1. **Clone the repository:**
```bash
git clone https://github.com/FtmDhn/ftm-dh-music.git
cd ftm-dh-music
```
2. **Setup:** Ensure the project structure remains intact (keep the img/ and js/ folders alongside index.html).

3. **Run:** Simply open index.html in your preferred web browser.
4. **Explore:** Find your favorite songs, hit play, and save the ones you love to your Library.
